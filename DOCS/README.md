# JAC Works Documentation

This directory is the shared home for durable project documentation and design decisions.

Use it for:
- game design and progression decisions;
- architecture and infrastructure decisions;
- ADRs (Architecture Decision Records);
- networking/protocol design;
- class, combat, boss and encounter design;
- collaboration/workflow conventions;
- decisions that future developers and AI agents need to understand.

## Principle

Chat is for exploration. GitHub documentation is for decisions worth preserving.

Ideas being discussed should be marked as proposals or drafts. Once the team agrees on a decision, record its status and rationale so later work does not have to reconstruct the decision from chat history.
