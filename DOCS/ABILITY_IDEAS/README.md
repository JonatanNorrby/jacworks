# Project Energy → JAC Works: Ability & Evolution Inspiration

**Status:** Draft / idea library, **not approved JAC Works game design or implemented abilities**.

This folder provides a structured inspiration library adapted from Christoffer's *Project Energy / Energy Arena*. The source includes **30 base abilities, 60 evolutions**, and JAC Works curation covering **24 proposed combos** plus a short initial favorites list. Keep original behaviors distinct from proposed JAC adjustments.

- [Ability & Evolution Library (Excel)](./JAC_Works_Ability_Evolution_Library.xlsx) — filterable six-sheet workbook for team review.
- [Ability Idea Library (Markdown)](./JAC_Works_Ability_Idea_Library.md) — text-readable library suitable for GitHub previews and AI-agent analysis.
- [Skill Mutation & Crafting Proposals](../SKILL_MUTATION_CRAFTING_PROPOSALS.md) — related independent draft proposals.

**Suggested team review:** Axel might start with *Solar* (Shaman/Warlock-flavored ideas), Jonatan with *Void* (Rogue/Shadow-flavored ideas). Both should review combos across other classes as mechanics can be renamed, re-elemented or moved between classes. JAC Works may feature fewer simultaneous enemy targets than Energy Arena; many AoE evolutions can be adapted into one primary target + one or two secondary targets.

**Open decisions:** Evolution progression could involve talents, boss drops, crafting, or hybrids; **none is decided by this document**. The project uses ADRs in [../ADR/](../ADR/) for accepted durable decisions. Do not implement entries from the library without discussion/approval.

For agents: See [../AGENTS.md](../AGENTS.md) and accepted ADRs before coding; do not silently treat draft mechanics or origin/class names as canonical.
