# JAC Works: Unified Skill & Evolution Ideas

**Status:** Draft / idea library, **not approved JAC Works game design or implemented abilities**.

Start with the **[canonical indexed Markdown library](./JAC_Works_Ability_Idea_Library.md)**. It combines Christoffer (Chris)'s *Project Energy / Energy Arena* with our documented JAC brainstorms in one browseable library: categories, stable IDs, tags, provenance, base/evolution/combination relationships and status.

**182 indexed ideas:** 30 source abilities + 60 source evolutions + 24 preserved combos (12 source-labeled, 12 JAC proposals) + 54 earlier JAC mutations + 7 interview concepts + 3 earlier JAC combination suggestions + 4 new speculative hybrids. The 25 JAC base contexts are navigation aids, excluded from the idea count. Recipe aliases, adaptation annotations and favorites are references, not extra abilities.

- [Ability & Evolution Library (Excel)](./JAC_Works_Ability_Evolution_Library.xlsx) — original six sheets preserved, with Unified Index and JAC Ideas companion sheets. Markdown is canonical; synchronize companion sheets when ideas change.
- [Ability Idea Library (Markdown)](./JAC_Works_Ability_Idea_Library.md) — text-readable library suitable for GitHub previews and AI-agent analysis.
- [Historical Skill Mutation & Crafting Proposals](../SKILL_MUTATION_CRAFTING_PROPOSALS.md) — provenance and recipe aliases; its skill ideas are incorporated in the canonical library. Economy/acquisition suggestions remain historical proposals.

Original Energy effects remain distinct from JAC interpretations. Original class labels, numerical values, priorities, target counts and suggested routes are source context or draft proposals, not future class assignments or approved balance. Cross-source hybrids are explicitly speculative; they are not Chris's original entries or accepted designs.

**Open decisions:** Evolution progression could involve talents, boss drops, crafting, or hybrids; **none is decided by this document**. The project uses ADRs in [../ADR/](../ADR/) for accepted durable decisions. Do not implement entries from the library without discussion/approval.

For agents: See [../AGENTS.md](../AGENTS.md) and accepted ADRs before coding; do not silently treat draft mechanics or origin/class names as canonical.
